# CAD Mechanism Animator

把机械 CAD 装配变成"会动、可交互、能离线打开"的网页动画。核心思想：**不直接渲染原始 B-rep（太重且不含运动信息），而是 解析装配 → 提取参数 → 参数化重建 → 建立运动学 → 交互打包**。

## 工作流程（5 阶段）

### 阶段 0：先读懂机构（动手前）

打开模型预览图或装配，回答四个问题：
1. 哪些是**固定件**（壳体/机架）、**动力输入**（飞轮/曲轴/电机）、**输出**？
2. 动力传递**路径**是什么（经过哪些轴/齿轮/连杆）？
3. 有哪些**运动副**：转动副（轴、齿轮、轴承）、移动副（拨叉、活塞、阀芯）、齿轮副、凸轮副、带/链传动？
4. 有几种**工况/状态**（变速箱的挡位、发动机的冲程、泵的循环）？

把每个运动件的"自由度 + 被谁驱动"列成表，这是后续运动学的骨架。

### 阶段 1：解析 CAD 装配

用 `scripts/extract_instances.py` 遍历装配树，提取每个零件实例的世界坐标、包围盒、层级：

```bash
python scripts/extract_instances.py <model.stp> -o instances.json
```

依赖 `cadquery`（含 OCP/OpenCascade）。用输出的坐标/包围盒定位轴、齿轮、连杆的位置。不要把整个 STP 直接加载进网页。

### 阶段 2：识别运动部件并提取参数

按 B-rep 面类型区分零件：圆柱面（轴/孔）、齿面（齿轮）、平面（壳体）。

- **齿轮**：`scripts/measure_gears.py` 自动测齿数（截面轮廓 FFT + 数峰）、齿顶圆、齿宽、螺旋角：
  ```bash
  python scripts/measure_gears.py <model.stp> gears.json -o gear_params.json
  ```
  `gears.json` 列出实例 id 与轴中心（从 instances.json 读取）。
- **其他参数**：连杆测孔距/行程、凸轮测升程轮廓、带轮测直径、曲轴测曲柄半径。

关键换算（详见 [references/gear-geometry.md](references/gear-geometry.md)）：
模数 `m = da/(z+2)`；节圆 `d = mz`；外啮合中心距 `a = m(z1+z2)/2`；传动比 `i = z从动/z主动`。

### 阶段 3：参数化重建几何（Three.js）

以 `assets/template.html` 为起点，用提取的参数生成**轻量几何**：
- 渐开线直齿/斜齿齿轮（`buildGear`，含齿顶/齿根/渐开线）、结合齿圈、同步器、拨叉
- 圆柱轴、轴承、连杆、活塞、壳体；用 `CylinderGeometry`/`ExtrudeGeometry`/`LatheGeometry` 组合
- 材质区分：钢（深灰、高金属度）、铸铝壳体、高亮色（当前动力流）；深色背景 + 网格地面

复制模板后，把"机构定义"和"运动学"替换为当前模型的参数。

### 阶段 4：建立运动学（核心）

在主循环里，让每个运动件的位置 = 驱动件位置 × 传动关系：
- **转动副**：绕自身轴累积角度；**移动副**：沿轴平移
- **齿轮副**：外啮合转向相反、内啮合相同；线速度相等 → `ω从动 = -ω主动·z主动/z从动`
- **多级传动**：总传动比为各级连乘；**惰轮**只改变方向，不改变速比
- **空套齿轮**：未挂挡时独立空转（不随轴）；**同步器/离合器锁死**后与轴同速
- **直接挡**：锁死输入与输出（i=1）；**超速挡** i<1；**倒挡**经惰轮反向
- 用**状态机**描述切换过程（如：摘挡 → 同步 → 挂挡），见 [references/kinematics.md](references/kinematics.md)

### 阶段 5：驱动、交互、打包

- 主循环 `requestAnimationFrame`：按当前状态推进各件角位移/位移；更新仪表
- 交互：工况/挡位按钮、键盘、`OrbitControls` 拖拽缩放、`CSS2DRenderer` 零件标签、仪表（转速/传动比/车速）、动力流高亮
- 打包为离线单文件（关键，否则 file:// 双击会被 CORS 拦截）：
  ```bash
  python scripts/build_single.py <app.html> -o <演示.html>
  ```
  该脚本把所有 ES module 内联为 Blob URL 动态加载。

## 举一反三：遇到新机构怎么办

1. 先做阶段 0 的四问，**画出运动传递链**，不要急着写代码。
2. 判断每个运动副的**约束与传动比**：运动件的每个自由度，都要能追溯到某个驱动件和确定的比例/规律。
3. 能参数化就参数化：用少量参数（齿数、行程、相位角）驱动几何，而不是摆静态模型。
4. 找不到参数时，用阶段 1/2 的脚本从 CAD 实测；周期性运动（齿轮、凸轮、曲轴）优先用 FFT/截面法。
5. 先让一个工况正确动起来，再扩展其他工况和交互。

## 常见机构速查

| 机构 | 运动副 | 关键参数 / 规律 |
|---|---|---|
| 齿轮变速箱 | 转动+齿轮副+移动(拨叉) | 齿数、传动比、同步器锁死、空套、惰轮 |
| 曲柄滑块(发动机/活塞泵) | 转动+转动副+移动 | 曲柄半径 r、连杆长 l、相位；x≈r·cosθ+√(l²−r²sin²θ) |
| 凸轮机构 | 转动+移动(从动件) | 升程轮廓、基圆、压力角；从动件按轮廓往复 |
| 差速器 | 锥齿轮+行星架 | 左右半轴 ωL+ωR=2ω架；转弯时差速 |
| 带/链传动 | 转动+挠性件 | 轮径比、包角；同向、线速度相等 |
| 行星齿轮组 | 多齿轮副+系杆 | 太阳/齿圈/系杆转速满足 (ωs−ωc)/(ωr−ωc)=−zr/zs |
| 泵/压缩机 | 转动/移动+容积周期 | 转子相位、排量周期、进排出口 |

各机构的几何与运动学细节见 [references/kinematics.md](references/kinematics.md)；齿轮几何细节见 [references/gear-geometry.md](references/gear-geometry.md)；踩坑（file 协议、rAF 冻结、headless 黑屏）见 [references/troubleshooting.md](references/troubleshooting.md)。

## 验证

- 用真实浏览器（或 Browser Use）逐工况检查：转向、转速、传动比、标签、高亮是否正确。
- 用 `scripts/build_single.py` 打包后，务必通过 `file://` 打开确认离线可用。
- headless 截图偶发黑屏（软件渲染时序）时多重试几次，勿误判为 bug。
