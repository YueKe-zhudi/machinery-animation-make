# 方法论：让任意机械模型动起来

本文是"举一反三"的核心：拿到一个陌生的机械 CAD/STP 模型，如何一步步把它变成
可交互、可离线的工作原理动画。配合 [../skill/SKILL.md](../skill/SKILL.md) 使用。

## 总览：核心思想

**不要直接渲染原始 CAD，而是：解析 → 提参数 → 参数化重建 → 建运动学 → 交互打包。**

原始 B-rep 太重（几十上百 MB）、是静态的、不含"谁带动谁"的运动信息。
我们只把它当作"参数来源"，最终在网页里用少量参数生成轻量、可动的几何。

---

## 阶段 0：先读懂机构（最重要，别急着写代码）

打开模型预览图（或导出几张截图），回答四个问题：

1. **固定件 / 输入 / 输出**：哪些是壳体/机架（不动）？动力从哪里来（飞轮、曲轴、电机、液压缸）？输出到哪里？
2. **运动传递路径**：动力依次经过哪些轴、齿轮、连杆、皮带？画出一条链。
3. **运动副类型**：
   - 转动副：轴、齿轮、轴承、曲柄
   - 移动副：拨叉、活塞、阀芯、滑块
   - 齿轮副：外啮合 / 内啮合 / 锥齿 / 蜗轮蜗杆
   - 其他：凸轮副、带传动、链传动
4. **工况 / 状态**：有几种工作状态？（变速箱的挡位、发动机的冲程、泵的循环、机器人的姿态）

产出一张表：**每个运动件 → 它的自由度、被谁驱动、传动关系**。这是后续运动学的骨架。

> 经验：80% 的 bug 来自阶段 0 没理清。把传递链画清楚，后面是机械实现。

## 阶段 1：解析 CAD 装配

目的：定位每个零件的位置，而不是把整个 STP 加载进网页。

```bash
python skill/scripts/extract_instances.py <model.stp> -o instances.json
```

脚本做的事：
- 用 OpenCascade（OCP）的 `STEPCAFControl_Reader` 读取
- 遍历 XCAF 装配树（递归 `walk`），对每个零件实例提取：
  - 零件名、层级深度
  - 世界坐标平移（x,y,z）
  - 世界包围盒（bbox）

用输出的坐标/包围盒：
- 确定**轴的位置和方向**（一串圆柱/齿轮的中心连线）
- 确定**齿轮、连杆、壳体**的位置
- 估算零件尺寸（包围盒）

**坐标系**：STEP 里的轴可能沿任意方向。先确定主轴方向，再在网页里统一映射
（本项目模板统一把齿轮轴映射到世界 X 轴）。

## 阶段 2：识别运动部件并提取参数

### 2.1 按 B-rep 面类型分类零件

| 面类型 | 对应零件 |
|---|---|
| 圆柱面（同轴） | 轴、销、孔、轮毂 |
| 齿面（周期性起伏的圆柱/锥面） | 齿轮、齿圈、锥齿轮 |
| 平面 | 壳体、机架、拨叉 |
| 复杂曲面 | 凸轮、泵体、叶片 |

### 2.2 齿轮参数自动测量

```bash
python skill/scripts/measure_gears.py <model.stp> gears.json -o gear_params.json
```

`gears.json` 列出要测的齿轮实例 id 与轴中心（轴中心从 instances.json 读）：

```json
{ "5": {"tag":"input_drive", "cx":0, "cy":0},
  "6": {"tag":"counter_input","cx":0, "cy":70.5} }
```

**算法原理（对直齿/斜齿都适用）**：
1. 三角化零件表面得到点云
2. 齿顶区域（r > rmax·0.97）确定**齿宽**和齿宽中点 zc
3. 取 zc 中段截面，按周向角 θ 分箱取最大半径，得到**周向轮廓**
4. 轮廓信号做 **FFT**，在合理齿数范围（9–120）取主频 → 齿数；再用**迟滞阈值数峰**交叉验证
5. **螺旋角**：取齿宽前后两个截面，比较同一齿的周向相位差 Δφ，
   `β = atan(r·Δφ/Δz)`

输出：齿数、齿顶圆、齿宽、螺旋角。

### 2.3 其他参数

- 模数：`m = da/(z+2)`，向标准模数取最近值
- 中心距：两轴距离；或 `a = m(z1+z2)/2`
- 连杆：测两端孔中心距离（孔距）、行程
- 凸轮：测轮廓向径随角度变化（升程曲线）、基圆
- 曲轴：测曲柄半径、各缸相位
- 带轮/链轮：测节圆直径

## 阶段 3：参数化重建几何

用提取的参数生成**轻量几何**，而不是加载原始 B-rep。

| 零件 | Three.js 方法 |
|---|---|
| 直齿齿轮 | 渐开线二维 `Shape` → `ExtrudeGeometry` |
| 斜齿齿轮 | 渐开线 extrude + 顶点绕轴扭转 |
| 轴、销、毂 | `CylinderGeometry` |
| 连杆、拨叉、支架 | 二维轮廓 + `ExtrudeGeometry` |
| 飞轮、盘类、回转体 | `LatheGeometry`（车削） |
| 结合齿圈 | 小直齿/小方块阵列 |
| 同步器 | 花键毂 + 可滑动接合套（短圆筒） |
| 壳体、机架 | 箱体组合，可用半透明材质 |
| 轴承 | 内/外圈 + 滚珠阵列 |

**渐开线齿形**：
- 齿廓是基圆展开的渐开线：`x = rb(cos t + t sin t)，y = rb(sin t − t cos t)`
- 一个齿的圆心角 = 2π/z；齿根圆→基圆用圆弧，基圆→齿顶圆用渐开线
- 演示中可用少量直线段近似渐开线，视觉足够

**材质**：
- 钢：`metalness 0.9, roughness 0.35`，深灰
- 铸铝壳体：略亮、粗糙度高
- 当前动力流：emissive 橙色高亮
- 深色背景 + 网格地面，突出机构

## 阶段 4：建立运动学（核心）

### 4.1 通用建模

每个运动件维护一个广义坐标（角度 θ 或位移 x）。每帧：

```
主动件.θ += ω·dt
各从动件 = 由约束求解
周期性：θ %= 2π
```

原则：**每个自由度都要能追溯到一个驱动件和一条确定的比例/几何关系。**

### 4.2 齿轮传动

- 啮合处节圆线速度相等：`ω1·r1 = ω2·r2`
- 外啮合（转向相反）：`ω2 = −ω1·z1/z2`
- 内啮合（齿圈，转向相同）：`ω2 = ω1·z1/z2`
- 多级传动：总传动比 = 各级连乘
- 惰轮：同时啮两轮，齿数不进速比，只改方向（倒挡原理）

### 4.3 变速箱特殊结构

- **空套齿轮**：经轴承套在轴上，未挂挡时**独立空转**（与轴不同速）
- **同步器**：花键毂随轴转，接合套轴向滑动；换挡时先经锥面/锁环使目标齿轮
  与轴**同步**，再滑过结合齿圈把齿轮与轴**锁死**
- **直接挡**：同步器锁死输入轴与输出轴，i=1（无齿轮副）
- **超速挡**：输出比输入快，i<1
- **倒挡**：经惰轮，输出反向

建模时，**轴和空套齿轮要分别存储角速度**；挂挡（锁死）后再令二者相等。

### 4.4 其他机构

- 曲柄滑块：`x = r·cosθ + √(l²−r²sin²θ)`，连杆摆角 `φ = asin(r sinθ/l)`
- 凸轮：从动件升程 = 轮廓函数(θ)（等速/简谐/摆线等运动规律）
- 差速器：`ωL + ωR = 2ω架`，行星齿轮既公转又自转
- 行星齿轮组：`(ωs−ωc)/(ωr−ωc) = −zr/zs`
- 带/链：线速度相等、同向，`i = r从动/r主动`

### 4.5 工况状态机

用状态机描述切换。以变速箱为例：

```
NEUTRAL（空套齿轮各自空转）
  → 踩离合/摘挡（动力断开）
  → 接合套滑动 + 同步（目标齿轮转速插值到同步值）
  → 锁死（ENGAGED，动力经该挡传递）
```

切换给 0.3–0.6s 过渡，避免突变。

## 阶段 5：驱动、交互、打包

### 5.1 主循环

`requestAnimationFrame`：
1. 按当前状态推进各件角位移/位移
2. 更新仪表
3. 渲染 3D 与标签

### 5.2 交互

- 工况/挡位按钮、键盘快捷键
- `OrbitControls`：拖拽旋转、滚轮缩放、右键平移
- `CSS2DRenderer`：零件标签跟随 3D
- 仪表盘：转速、传动比、车速等
- 动力流高亮：当前路径 emissive

### 5.3 离线单文件打包（关键）

```bash
python skill/scripts/build_single.py <app.html> -o <演示.html>
```

**为什么必须打包**：多文件版用 importmap + ES module，`file://` 双击会被
CORS 拦截黑屏。

**打包原理**：
- 扫描主模块所有 import，把模块（three、addons）内联为 Blob URL
- 主代码静态 import 改为动态 `await import(blobURL)`
- addon 内部 `from 'three'` 改写为 three 的真实 Blob URL

**两个不能做的事**：
1. 不能把多个模块源码简单拼进一个 `<script>` —— 各模块顶层私有变量同名
   （如 `_ray`），报 `Identifier already declared`；必须用 Blob 保持模块作用域隔离
2. addon 里不能填变量名当模块说明符 —— 说明符必须是 URL，要用占位符运行时替换

## 隐藏标签 / headless 的注意事项

- **隐藏标签 rAF 冻结**：自动化工具（如 headless 浏览器）页面可能
  `visibilityState=hidden`，`requestAnimationFrame` 不触发。
  - 双驱动：rAF + `setInterval(...,30)` 兜底
  - 提供静态跳转函数（如 `jumpToState(s)`），不依赖动画累积
  - 支持 URL hash 直接进入工况
- **headless 截图偶发黑屏**：`--disable-gpu` 软件渲染 + 顶层 await，
  第一帧可能没画完；多重试几次、加大 `--virtual-time-budget`（≥30000）。
  真实浏览器正常即视为通过。
