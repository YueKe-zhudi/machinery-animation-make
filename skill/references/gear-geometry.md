## 基本参数与换算

| 量 | 符号 | 公式 / 说明 |
|---|---|---|
| 齿数 | z | 一周的齿数（整数） |
| 模数 | m | 齿距/π，标准系列；决定齿的大小 |
| 压力角 | α | 标准 20°（也有 14.5°） |
| 分度圆(节圆) | d | `d = mz` |
| 齿顶圆 | da | `da = d + 2m = m(z+2)`（外齿） |
| 齿根圆 | df | `df = d − 2.5m = m(z−2.5)` |
| 基圆 | db | `db = d·cosα`（渐开线起点） |
| 齿顶高 | ha | `ha = m`；齿根高 `hf = 1.25m` |
| 齿宽 | b / fw | 沿轴线方向的厚度 |

**由实测反推模数**：从 CAD 测得齿顶圆 da 与齿数 z，则 `m = da/(z+2)`，再向标准模数（1, 1.25, 1.5, 1.75, 2, 2.5…）取最近值。

## 渐开线与齿形

渐开线（involute）是齿轮齿廓的标准曲线，由一条绕基圆展开的直线端点生成：

```
inv(α) = tan α − α            （渐开线函数，α 用弧度）
给定滚动角 t：
  x = rb·(cos t + t·sin t)
  y = rb·(sin t − t·cos t)
```

构造一个齿的二维轮廓（极坐标/直角）：
1. 齿根圆 → 基圆用一段圆弧（或径向线）连接；
2. 基圆 → 齿顶圆用渐开线（左右各一条，关于齿中心线对称）；
3. 齿顶用齿顶圆弧连接左右渐开线；
4. 一个齿的圆心角 = `2π/z`，齿厚约占齿距一半（齿厚角 ≈ π/z，再按变位/侧隙微调）。

把该齿形 `ExtrudeGeometry`（直齿）或加扭转（斜齿）拉伸，绕轴旋转复制 z 份。

## 斜齿与螺旋角

- 斜齿轮的齿沿轴线有螺旋角 β（常见 15°–35°），啮合更平稳。
- 端面（垂直于轴）与法面（垂直于齿）参数不同：`mn = mt·cosβ`（法向模数 = 端面模数×cosβ）。
- **旋向**：沿轴线看，齿向右上方为右旋（R），反之为左旋（L）。一对啮合斜齿轮旋向相反、β 相同。
- 斜齿 extrude：拉伸时顶点绕轴扭转，扭转角 = `(b·tanβ)/r`（r 为节圆半径）。
- 从 CAD 测 β：取齿宽前后两个截面，比较同一齿的周向相位差 Δφ，
  `β = atan(r·Δφ / Δz)`（`measure_gears.py` 已实现）。

## 啮合、中心距与传动比

- **外啮合**：两轮转向相反；**内啮合**（齿圈）：转向相同。
- 标准外啮合中心距：`a = (d1 + d2)/2 = m(z1+z2)/2`。
- 啮合处节圆线速度相等：`ω1·r1 = ω2·r2`，故
  `ω2 = −ω1·z1/z2`（外啮合负号）。
- **传动比**（变速箱行业，输出/输入的减速比，常显示为 1/i 的"挡速比"）：
  一对齿轮 `i = z从动/z主动`；多级 `i总 = i1·i2·…`。
- **惰轮**（idler）：同时与两个齿轮啮合，齿数不进入速比，只改变转向（倒挡原理）。
- 配算节圆凑中心距：当给定齿数与固定中心距 a 时，可令
  `m = 2a/(z1+z2)`，两轮节圆半径 `r1 = a·z1/(z1+z2)`、`r2 = a·z2/(z1+z2)`。

## 同步器、结合齿圈与空套

手动变速箱换挡的关键：
- **空套齿轮**：齿轮通过轴承套在轴上，未挂挡时与轴**不同速**（可独立空转）。
- **结合齿圈（dog gear / 同步锥）**：齿轮侧面带一圈直齿（结合齿）。
- **同步器（synchronizer）**：花键毂随轴转，套着可轴向滑动的接合套；换挡时
  接合套先经锁环/锥面使目标齿轮与轴**同步**，再滑过结合齿圈把齿轮与轴锁成一体。
- 锁死后：该齿轮与轴同角速度，动力经该挡位齿轮副传递。
- 建模简化：结合齿圈用一圈小直齿（`TorusGeometry` 齿面或小方块阵列）；
  接合套用带内齿的短圆筒；换挡动画 = 接合套沿轴滑动 + 目标齿轮由"空转"变"同速"。

## Three.js 构建要点

- 齿轮整体放在一个 `Group`，其局部 Z 轴（或 X 轴）与齿轮轴线对齐；
  旋转时只更新该 Group 绕轴的 `rotation`。
- 渐开线齿形：`THREE.Shape` 画二维齿 → `ExtrudeGeometry`（直齿）；
  斜齿需手动对每层截面顶点加扭转后再 `BufferGeometry` 建面。
- 材质：`MeshStandardMaterial`，钢 `color 0x9aa3ad, metalness .9, roughness .35`；
  齿面较亮、齿侧略暗；当前动力流用橙色 emissive 高亮。
- 配对齿轮齿顶圆之间留微小侧隙（0.5–1mm），避免视觉穿插。
- 齿圈（内齿）用内渐开线，或视觉上用内圈小方块阵列近似。
