## 通用建模法

每个运动件维护一个"广义坐标"（角度 θ 或位移 x），每帧由驱动件与约束更新：

1. 给每个运动副编号，明确类型（转动 R / 移动 P / 齿轮 G / 凸轮 C）。
2. 确定**主动件**（输入），其余为从动；从动件坐标由主动件经约束解出。
3. 每帧：`主动件.θ += ω·dt`，再按约束依次求各从动件。
4. 周期性运动用角度 `θ %= 2π`；多件相位差用初始偏置角表示。

核心原则：**每个自由度都要能追溯到一个驱动和一条确定的比例/几何关系**。

## 变速箱（多挡位状态机）

**角速度传播（给定输入轴 ωIn）**：
- 中间轴：`ωCnt = ωIn · z常啮合主动/z常啮合从动`（三轴式常啮合）。
- 某挡位挂入时，第二轴（输出）：
  `ωOut = ωCnt · z中间轴该挡/z第二轴该挡`（外啮合带负号）。
- 直接挡：`ωOut = ωIn`（同步器锁死，中间轴可仍转但不输出）。
- 倒挡：经惰轮，`ωOut` 符号为负。
- 空挡：第二轴无驱动，`ωOut = 0`（或保持惯性衰减）；各空套齿轮自由空转。

**换挡状态机**（教学演示用）：
```
NEUTRAL（空套齿轮各自空转）
  → 踩离合/摘挡（动力断开）
  → 接合套向目标滑动，同步锥使目标齿轮与轴转速一致（SYNCING）
  → 接合套滑过结合齿圈锁死（ENGAGED，动力经该挡传递）
```
切换时给一个 0.3–0.6s 的过渡：接合套位置插值 + 目标齿轮转速从"空转值"插值到"同步值"。

**空套齿轮视觉**：未挂挡齿轮按各自啮合关系有独立转速（演示中可让其缓慢空转）；
挂挡后该齿轮与轴同速。注意空套齿轮与其所在轴的转速要分开存储。

## 曲柄滑块

发动机活塞、活塞泵、压缩机的基础。曲柄半径 r，连杆长 l，曲柄角 θ：

```
活塞位移（沿气缸轴，从曲柄中心起）:
  x(θ) = r·cosθ + √(l² − r²·sin²θ)
连杆摆角:
  φ = asin( r·sinθ / l )
```
- 曲柄匀速转动（`θ += ωdt`）；活塞位置由上式，连杆两端分别接曲柄销与活塞销。
- 多缸机：各缸曲柄相位差（直列四缸 0°/180°/180°/0°，点火间隔 180°）。
- 死点：θ=0（外止点）、θ=π（内止点），活塞速度为 0。
- 几何：曲柄（偏心圆盘/曲柄臂）、连杆（两端带孔的杆）、活塞（圆柱/方块）、气缸。

## 凸轮机构

- 凸轮以 ω 转动，从动件（挺柱/挺杆）按凸轮轮廓做往复移动（或摆动）。
- 给定凸轮转角 θ，从动件升程 s = 轮廓函数（盘形凸轮：轮廓向径 − 基圆半径）。
- 常见运动规律：等速、等加速等减速、简谐（余弦）、摆线（正弦加速度）。
- 例（对心直动，简谐升程，升程 h，作用角 β）：
  升程段 `s = h/2·(1 − cos(π·θ/β))`；回程段对称。
- 压力角：从动件受力方向与运动方向夹角，一般 ≤ 30°。
- 建模：凸轮用 `LatheGeometry`/`ExtrudeGeometry` 按轮廓生成，从动件每帧用 s 定位。

## 差速器

汽车转弯时允许左右驱动轮以不同转速转动：
```
ωL + ωR = 2·ωC        （C 为行星架/差速器壳，由主减速器从动齿轮驱动）
直线行驶: ωL = ωR = ωC
转弯: 一侧增加 Δω，另一侧减少 Δω
```
- 内部：2（或4）个行星锥齿轮随架公转并自转，与左右半轴锥齿轮啮合。
- 建模：锥齿轮用 `CylinderGeometry` 锥化 + 锥齿近似；行星齿轮既随架公转又绕自身轴自转。
- 主减速器：一对螺旋锥齿轮（或准双曲面），大减速比、转向折 90°。

## 行星齿轮组

由太阳轮 s、齿圈 r、行星轮（装在系杆/行星架 c 上）组成。基本关系：
```
(ωs − ωc) / (ωr − ωc) = − zr / zs
```
（行星轮为惰轮，齿数不直接出现）。
- 固定不同元件得到不同挡位：固定齿圈（太阳输入、系杆输出）→ 大减速；
  固定系杆 → 反向减速；固定太阳 → 超速；任意两元件锁死 → 直接挡。
- 自动变速箱用多排行星组 + 离合器/制动器组合出多个挡位。
- 建模：行星轮同时绕太阳公转（随系杆）和自转；`ωp = ωc − (ωs−ωc)·zs/zp`。

## 带 / 链传动

- 两轮（或多轮）间挠性件，线速度相等：`ω1·r1 = ω2·r2`，转向相同（开口传动）。
- 传动比 `i = r从动/r主动 = z从动/z主动`（链）。
- 建模：带用闭合曲线（两轮外公切线 + 包角弧）`TubeGeometry` 或拉伸扁带；
  链用链节阵列沿轨迹排布；可加纹理滚动表现运动。
- 包角过小会打滑，一般 ≥ 120°；张紧轮用于增包角/调节松紧。

## 泵 / 压缩机

- **齿轮泵**：一对啮合齿轮反向转动，齿槽与壳体间容积周期性变化，进油/出油口固定。
- **转子泵/叶片泵**：偏心转子 + 滑片，容积随转角变化。
- **往复泵**：曲柄滑块 + 进/排单向阀，活塞往复改变缸内容积。
- 建模关键：表现"容积周期"与"阀的开闭相位"；流体可用粒子/颜色随相位移动。
- 排量随转角的周期变化是核心，可叠加仪表显示瞬时流量/压力。
